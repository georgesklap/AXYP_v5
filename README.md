# ΑΞΥΠ — εφαρμογή κινητού (μόνο προβολή)

Εφαρμογή PWA για Android και iPhone. Εμφανίζει άδειες, βάρδιες, νυχτερινά/πενθήμερα και οφειλόμενα ρεπό,
όπως τα δημοσιεύει το κουμπί **ΔΗΜΟΣΙΕΥΣΗ** του Excel ΑΞΥΠ.

* Τα υπηρεσιακά δεδομένα βρίσκονται ΜΟΝΟ κρυπτογραφημένα στο `data/axyp.json`
  (PBKDF2-SHA256 600.000 επαναλήψεις → AES-256-CBC + HMAC-SHA256).
* Ο κωδικός ή κάποιο κλειδί δεν υπάρχει πουθενά σε αυτό το repository.
* Η εφαρμογή δεν υπολογίζει τίποτα: εμφανίζει τις τιμές του Excel.

Αρχεία: `index.html`, `app.js`, `style.css`, `manifest.webmanifest`, `sw.js`, `icons/`.
Το `data/axyp.json` δημιουργείται και ενημερώνεται αποκλειστικά από τη ΔΗΜΟΣΙΕΥΣΗ.
